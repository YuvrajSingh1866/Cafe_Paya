# Cafe paya — Client Website

Premium responsive React/Vite website for Cafe paya, an Indian restaurant in Mississauga, Ontario.

## Verified listing details used
- Business name: Cafe paya
- Category: Indian restaurant
- Location: Mississauga, ON L5B 3R2, Canada
- Services visible in supplied Google Maps screenshot: Dine-in, Takeaway
- Google Maps CID: 14765936149804910160

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Important
The contact form is intentionally frontend-only. It validates input and shows a status message, but does not claim to deliver messages until a real backend/email provider is connected.

The gallery uses clearly labeled representative imagery rather than claiming those photos are actual Cafe paya photographs.
